# Texture credits

All textures in this folder are CC0 (public domain) from
[Poly Haven](https://polyhaven.com) — 1K JPG diffuse + GL normal maps.

Sets: leafy_grass, brown_mud, rock_face, coast_sand_01, snow_02,
forest_ground_04, forest_leaves_03, burned_ground_01, rocky_terrain,
planks_brown_10, bark_brown_01, stone_tile_wall, plastered_wall_02,
clay_roof_tiles.

The `.gdignore` keeps Godot's importer away — the game loads these at
runtime with `Image.load_from_file` (see `TexF.pbr_tex`).
